# spec

3構成（Vanilla、Astro、Next.js）に共通の仕様と素材を置く。

| パス | 中身 |
|---|---|
| `requirements.md` | 要件書。ページ一覧と受け入れ条件 |
| `wireframes.md` | サイトマップと、ひな形ごとの画面設計 |
| `design/` | 見本の HTML と共通 CSS。HTML の約束は `design/README.md` |
| `assets/images/` | 写真 |
| `assets/copy.md` | 静的ページの文言と、写真の置き場所・代替テキスト |

## 写真

`assets/images/` の写真は Unsplash から取った。[Unsplash のライセンス](https://unsplash.com/license)で、複製と再配布が認められている。

`hero.jpg` だけは、ダウンロードしたまま（6832×4270、2.9MB）置いている。Phase 1 で各構成が最適化する前提の素材なので、変換しない。ほかの写真は、長辺1920px、JPEG の品質75に縮小してある。
